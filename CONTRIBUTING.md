## Contributing Guide

Thanks for helping improve Hermex.

## Getting started

1. Fork and clone the repository.
2. Read:
   - `README.md`
   - `docs/PLAN.md`
   - `docs/ARCHITECTURE.md`
   - `docs/DEVELOPMENT.md`
   - `docs/LLM_INTEGRATION.md`
3. Create a feature branch from `main`, for example `feat/quest-ui-basic`.

## Contribution standards

- Use clear, respectful, and concise language.
- Any behavior change must be accompanied by docs updates.
- For API changes:
  - update `docs/ARCHITECTURE.md`,
  - include request/response expectations in PR description.

## Commit convention

Use Conventional Commits:
- `feat: ...`
- `fix: ...`
- `docs: ...`
- `refactor: ...`
- `chore: ...`

## Pull request checklist

- [ ] Briefly summarize behavior changes.
- [ ] Attach screenshots or recordings for gameplay/UI changes.
- [ ] Include reproduction steps for bug fixes.
- [ ] Update docs if scope changes.
- [ ] Confirm no secrets are committed.

## Communication

- Open larger ideas in an issue first.
- Smaller questions can be handled via draft PR discussion.
